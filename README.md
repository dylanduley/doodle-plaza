# Doodle Plaza

**Doodle Plaza** is a social space where everything is drawn by hand. Instead of uploading a photo, you draw your profile picture. Instead of typing every post, you draw it on a low-res pixel canvas or animate it frame by frame, inspired by the charm of Flipnote and Miiverse. The constraints are intentional: a small canvas and a limited palette keep every post personal, consistent, and quick to make.

Built with Next.js, TypeScript, and Supabase, with a custom pixel-drawing engine on the HTML Canvas API.

> **Status:** early development. Drawing, animating, guest profiles, and posting work end to end, with posts shared through Supabase. Replies and Yeah! are next.
> **Live demo:** https://doodle-plaza.vercel.app/

## What works today

- 320×120 pixel canvas, scaled up with crisp pixels
- Pen and eraser in three sizes, plus a fill bucket
- Three ink colors on a white canvas
- Zoom inside a fixed window with edge arrows that show hidden areas; pan with the arrows, arrow keys, scroll, Space-drag, or the hand tool
- Quarter-turn rotation (auto-fits the canvas) and a mirror flip view
- Undo / redo (50 steps), clear (undoable), save as PNG
- Keyboard shortcuts: `B` pen, `E` eraser, `G` fill, `H` hand, `[` `]` brush size, `1–3` colors, `R` / `Shift+R` quarter turn, `F` flip, arrow keys pan, `+` / `-` zoom, `0` reset view, `Ctrl/⌘+Z` undo, `Ctrl/⌘+Shift+Z` redo
- Works with mouse, touch, and stylus (Pointer Events)

## Animation

Open `/draw/animate` for a 320×180 flipbook editor (all the drawing tools, plus frames).

- **Frames:** up to 100. Add a blank frame or duplicate the current one to trace over, reorder, and delete (with one-click **Undo**). Each frame keeps its own undo history.
- **Onion skin:** the previous frame shows as a faded ghost under the one you're drawing, so movement lines up
- **Playback:** play/pause at 2, 4, 8, 12, or 24 fps. Drawing pauses during playback, so you always know which frame you're editing.
- **Shortcuts:** `,` / `.` previous/next frame, `N` new frame, `Shift+N` duplicate, `P` play, `O` onion skin
- **In the feed:** animations loop automatically, only while on screen (so a long feed doesn't waste battery), start paused for people who prefer reduced motion, and have a pause button

## Posting

Draw on `/draw`, add an optional caption (80 characters), pick a plaza, and post.

- **Validation:** an empty canvas or a missing plaza shows an inline message after the first attempt; the caption counter warns near the limit
- **States:** a "Posting…" spinner, an error with **Try again** that keeps your drawing, and a success banner on the new post's page
- **Safety:** leaving the page with an unposted drawing asks for confirmation; deleting a post asks first (focus starts on "Keep it")
- **Where posts go:** Supabase (Postgres), through `src/lib/posts.ts`. You need a guest profile to post; the draw page tells you before you start drawing.
- **Try the error state:** open `/draw?simulateError=1`. The first post attempt fails, and Try again succeeds.
- Real posts from everyone appear at the top of the home and plaza feeds (above the sample posts) and on each person's profile at `/u/handle`. You can delete your own.

## Site UI (sample data)

- **Plaza home:** hero, "Popular this week" strip, a feed of posts, today's prompt, and a list of plazas
- **Plazas:** themed boards (Critters, Spooky Season, Tiny Worlds…) with their own feeds and a "Draw here" button
- **Post pages:** the drawing, its replies (typed or drawn), and more from the artist
- **Drawing-only posts:** every post is a drawing or animation (with an optional caption); text is only for replies
- **Profiles:** bio, stats, and posts
- **Yeah! button:** the plaza's "like", with an optimistic toggle
- "Make your profile" page (`/signin`): draw a 120×120 profile picture and pick a name and handle. It's a temporary guest profile for now; your picture shows in the header.
- 404 page and empty states
- Sample drawings are generated by the same pixel engine as the editor (`src/lib/pixel/doodles.ts`), so they look like real posts without shipping image files

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # drawing engine unit tests
npm run typecheck
npm run lint
```

## Project structure

```
src/
  app/                    Next.js routes (/, /draw)
  components/editor/      Drawing editor UI, useDrawingEditor (drawing) and useCanvasView (zoom/rotate/pan) hooks
  components/post/        Post composer, your-posts feed, local post page, guest profile
  components/ui/          Site UI: header, post cards, tiles, Yeah button, mascot
  lib/posts.ts            Posts API (Supabase)
  lib/profiles.ts         Guest profiles API (Supabase)
  lib/supabase/           Supabase clients for the browser, server, and proxy
  lib/mock/               Sample users, plazas, posts, and replies (until there is a backend)
  lib/pixel/              Framework-free drawing engine
    bitmap.ts             Indexed bitmap, Bresenham lines, brushes, flood fill
    history.ts            Snapshot undo/redo
    render.ts             Palette → RGBA
    codec.ts              Compact text encoding for saving drawings
    animations.ts         Sample animations for the feed
    constants.ts          Canvas size, palette, brush sizes
docs/
  brief.md                Problem, users, scope
  decisions.md            Design and technical decisions, with alternatives
  data-model.md           Database tables and access rules (Supabase)
```
